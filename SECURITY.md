# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in `tinyttl`, please do not open a public issue.

Instead, please report it privately by contacting the maintainer directly.

Include as much detail as possible:

- description of the issue
- possible impact
- steps to reproduce
- affected versions, if known

I will review reports on a best-effort basis and respond as quickly as possible.

## Supported versions

`tinyttl` is currently in active `0.x` development.

Security fixes, if needed, will be applied to the latest release line.
